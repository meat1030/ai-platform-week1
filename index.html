二、快速執行指南（怎麼執行）

可透過傳統 pip 或高效能環境管理器 uv 執行本專案：

Terminal / Command Prompt
# 1. 複製專案儲存庫
git clone https://github.com/meat1030/ai-platform-week1.git
cd ai-platform-week1

# 2. 配置 .env 金鑰檔案
echo "LLM_API_KEY=your_gemini_api_key_here" > .env

# 3. 安裝依賴套件並執行程式 (pip / uv 均支援)
python -m pip install google-genai python-dotenv
python app.py       # 亦可直接用 uv 執行: uv run app.py

四、本地 LLM (Ollama) vs 雲端 LLM (Gemini) 評估表

比較項目 本地模型 (如 Ollama / Llama 3) 雲端模型 (如 Gemini 2.5 Flash) 🌟 本專案採用
回應速度與算力 受限於本機 GPU/RAM，推論速度較慢 雲端高速算力，支援即時串流 (Streaming) 輸出
資料隱私與安全性 100% 本地運算，資料絕不上雲 資料經 API 傳送，需嚴格透過 .gitignore 防護金鑰
部署與運作成本 需自行配置硬體環境與模型權重 零硬體門檻，隨插即用，極適合 GitHub Actions CI/CD

五、AI 使用說明與賦能體驗

  • 工具應用：活用 VS Code、Google Gemini 2.5 Flash API 及 GitHub Actions。
  • 開發賦能：運用 AI 輔助建立語法架構、除錯 Python 環境與構建 Docker 化環境。
  • 機敏安全驗證：驗證 .gitignore 安全隔離，確保包含 LLM_API_KEY 之 .env 絕不上傳至版本控制歷史中。
