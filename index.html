📊 AI 股票與 ETF 投資分析助手

一、專案說明（做了什麼）

本專案基於 Python 與 Google Gemini API (gemini-2.5-flash)，針對台股金融股（如台中銀、中信金）及熱門 ETF 構建一款具備即時串流回應 (Streaming) 功能的投資輔助工具。

二、如何執行（執行步驟）

  1. 複製專案儲存庫：git clone https://github.com/meat1030/ai-platform-week1.git
  2. 建立 .env 環境變數檔並寫入：LLM_API_KEY=你的API金鑰
  3. 安裝必要 Python 套件：C:\Users\a0981\AppData\Local\Python\pythoncore-3.15-64\python.exe -m pip install google-genai python-dotenv
  4. 執行主程式：C:\Users\a0981\AppData\Local\Python\pythoncore-3.15-64\python.exe app.py
